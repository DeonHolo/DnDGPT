# Utility usefulness amendment

Utilities now need an accessible capability with reliable ordinary value, three plausible applications across two different noncombat problem types, and a comparison against the whole kit. Renaming the object in the same repair job counts once. Active powers should support player-initiated uses; Passive powers should fit common activities. Rare conditions can strengthen an otherwise useful capability. Written operations and limits support creative applications without granting unrelated effects or automatic success.

The full standard is the indexed `utility` amendment. The compact hardener and plugin skill point to it, and the generated index includes it in creation and Utility dependencies. Existing slots, fixed rarities, source distinctions and saved powers remain governed by their existing rules. This release makes no campaign writes.
