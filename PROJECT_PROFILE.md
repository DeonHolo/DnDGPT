# DnDGPT — Persistent Conversational RPG Companion

**Python · FastAPI · SQLite · OAuth 2.0 / PKCE · MCP / MCP Apps · JavaScript**

Built a ChatGPT-integrated RPG companion that keeps character, inventory and world state in an authenticated service and reusable dashboard while ChatGPT handles narration and adjudication.

- Developed account-owned SQLite persistence with transactional updates, optimistic concurrency, event history and idempotent roll receipts.
- Integrated OAuth-protected MCP tools and a seven-chapter fantasy interface, exercised in regular ChatGPT.
- Added automated coverage for authentication, ownership, retries, state recovery, rulebook integrity and reproducible plugin packaging.

**One line:** Built a persistent RPG companion connecting ChatGPT narration to an OAuth-protected Python backend and interactive campaign dashboard.

**Scope:** Active prototype. Do not claim complete executable rule coverage, production uptime, measured latency, public-directory approval or verified multi-account use.
