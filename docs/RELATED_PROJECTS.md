# Related projects

Reviewed October 19, 2026. These are documented projects with overlapping ideas, not an exhaustive market survey or independent tests of their advertised features.

| Project | Relevant overlap | Difference worth keeping clear |
| --- | --- | --- |
| [Questforge](https://github.com/adrianmelic/codex-questforge) | AI-run fantasy campaigns, persistent records and a packaged GM workflow. | A Codex-focused runner with local files and optional portable saves. See [the storage comparison](CAMPAIGN_STORAGE.md). |
| [DMCP](https://github.com/shawnrushefsky/dmcp) | An MCP server for AI dungeon masters, game state, dice and character information. | Documents a separate HTTP interface and several MCP clients; this review does not establish the same native ChatGPT presentation as DnDGPT. |
| [Text Adventure Handler MCP](https://github.com/narrowstacks/text-adventure-handler-mcp) | Persistent text adventures, dice resolution, world state and an optional web dashboard. | A general adventure server, rather than DnDGPT's particular homebrew rules and ChatGPT GM package. |
| [Copycat](https://github.com/KentaSUGAI/copycat-chatgpt-app) | A game delivered inside ChatGPT through an MCP endpoint and interactive widget. | A social-deduction party game, rather than a fantasy campaign. |

DnDGPT combines its own rules and lore, generated class kits, guided native Intelligent UI and an account-backed campaign dashboard beside the conversation. Those choices describe the project without claiming to have invented AI RPGs, MCP games or persistent campaign tools. This review does not establish a first-of-its-kind claim for that exact combination.
