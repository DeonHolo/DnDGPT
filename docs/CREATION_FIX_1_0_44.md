# Creation completion, starting Sovereign evolution and names

## Cause and resulting behavior

The retired confirm/start proposal returned creation_approval_retired, while older connected tool catalogs did not list the replacement top-level begin_adventure argument. The direct save already existed, but its compatibility path was incomplete. Final actual creation choices now use changes.begin_adventure=true inside the existing changes object. Top-level begin_adventure remains supported. Retired proposals return a noncommitting next_action handoff rather than an approval request or a blocking retirement error.

The final save validates the actual name, background, Your story, full class/Sovereign kit, opening and immutable class-budgeted outfit receipt. It commits the opening with no additional player acceptance, dashboard button or elapsed fictional time. Inspection and the legacy handoff themselves do not start play. A manual pause remains explicit, and owner/version/retry guards remain in place.

The earlier rules implemented guaranteed permanent Sovereign upgrades on gained levels but omitted the initial free choice. Creation now grants one free permanent Domain, General or Army upgrade, offered as five compatible choices within an existing creation board. Level 2 grants another. New saves account for the starting gift immediately. Older saves account for it once on their next ordinary committed save; already applied, explicitly selected creation overrides are recognized from their real owned permanent capabilities and retained as spent. No character choices, equipment or abilities are silently replaced.

## Presentation and art

Both games require actual saved names in prose, dialogue, offers, tooltips, upgrade explanations and dashboard display fields. S1/D3-style IDs stay inside tool arguments and references. Numbered choices retain their full option names. The clear-story section names the upgraded parent and acquired improvement explicitly.

Requested new images use the Gallery house direction: painted fantasy with gouache color, fine umber ink detail, dry-brush texture and inhabited scale. The palette follows the scene. Age of Convergence emphasizes the established meeting of Earth and the unfamiliar; Sovereign System emphasizes distinctive working domains, generals and forces. The player can request another style. Curated web artwork retains its original appearance and credit. [Copyable prompt](CAMPAIGN_ART_PROMPT.txt).
