# Launch scope

The first-play target is regular ChatGPT as GM with a reusable dashboard, saved state and Python roll helpers. Complete executable rule coverage is optional later work.

The public source includes no personal App binding, database or hosting credentials. Each operator must configure an HTTPS service, persistent database storage and OAuth, then verify the actual ChatGPT client.

Before wider distribution:

- Verify separate real accounts cannot read or update each other's records.
- Test supported client surfaces, reconnect behavior and database restoration.
- Document hosting availability, limits and operating costs for that deployment.
- Complete the applicable ChatGPT distribution/review process before claiming public installation availability.

Publishing a GitHub repository distributes source; it does not publish a ChatGPT directory listing or make a private App available to another account.
